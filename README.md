# Team Task Manager

A full-stack MERN (MongoDB, Express.js, React.js, Node.js) Team Task Management application with authentication, dashboard analytics, project management, and task tracking.

---

# Features

## Authentication
- User Registration
- User Login
- JWT Authentication
- Protected Routes

## Project Management
- Create Projects
- Fetch Projects
- Project Members

## Task Management
- Create Tasks
- View Tasks
- Task Status Tracking
- Task Priority Tracking

## Dashboard
- Total Tasks
- Completed Tasks
- Pending Tasks
- In Progress Tasks

---

# Tech Stack

## Frontend
- React.js
- React Router DOM
- Axios

## Backend
- Node.js
- Express.js

## Database
- MongoDB Atlas
- Mongoose

## Authentication
- JWT (JSON Web Token)
- bcryptjs
